# How-to guides

Task-oriented guides. Each one starts from a working graph and shows the
smallest change that solves the task, with real output.

| Guide | Use it when you need to |
| --- | --- |
| [Explain a decision after the run](explain-after-run.md) | Explain decisions once `invoke` has returned, or later from persisted records |
| [Handle human-in-the-loop interrupts](interrupts.md) | Record pauses, human answers, approvals, and the checkpoint to replay |
| [Correlate multi-agent runs and retries](multi-agent.md) | Follow one request across nodes, agents, retries, and services |
| [Capture MCP tool calls](mcp-tools.md) | Record tools served by a Model Context Protocol server |
| [Generate LLM-phrased explanations](llm-explanations.md) | Phrase explanations in natural language with a chat model |
| [Test disclosure policies](disclosure-policies.md) | Prove that each audience sees exactly what it should |
| [Configure failure modes](failure-modes.md) | Decide whether instrumentation failures may affect your graph |
